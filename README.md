# backend-carpass
CarPass é uma plataforma desenvolvida para registrar e acompanhar o histórico de manutenção de veículos.

A aplicação permite que proprietários cadastrem seus veículos e registrem serviços realizados ao longo do tempo, como revisões, trocas de óleo, manutenção de peças e outros cuidados com o carro.

O objetivo do CarPass é criar um histórico confiável e transparente que possa ser compartilhado futuramente com compradores, ajudando a comprovar a procedência e o bom cuidado do veículo no mercado de carros usados.

Este repositório contém o backend da aplicação, responsável pelo gerenciamento de usuários, veículos e registros de manutenção.
